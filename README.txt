GCAM GUIDE — сайт на HTML, CSS и JavaScript

КАК ОТКРЫТЬ:
1. Распакуйте архив в удобную папку, например Документы\gcam-guide-site.
2. Дважды нажмите index.html — сайт откроется в браузере.
3. Чтобы редактировать файлы, установите Visual Studio Code и откройте в нём всю папку.

ФАЙЛЫ:
- index.html — содержание сайта
- styles.css — оформление и адаптация под мобильные устройства
- script.js — раскрывающееся меню на телефонах

ПРИМЕЧАНИЯ:
- Для декоративного оформления не нужны изображения, загружаемые с внешних сайтов.
- Шрифт может загружаться из Google Fonts при наличии интернета; при отсутствии соединения будет использован системный шрифт.
- Это статический сайт: формы, база данных и система загрузки файлов не добавлены.
- Перед публикацией проверьте ссылки на источники APK и XML и добавляйте только проверенные материалы.
